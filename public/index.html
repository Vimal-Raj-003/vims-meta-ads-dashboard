Simple Tamil / Tanglish Guide — How to Use & Verify Your Dashboard

1. Meta Account Connect Pannuvathu Eppadi:
Mele irukkum "Connect Meta Account" button click pannunga. Ungal Meta Business Settings (alladhu Graph API Explorer)-il generate panna Access Token-ai paste panni ads_read, leads_retrieval, pages_show_list, pages_read_engagement permissions irukka endru verify pannunga. 2. Excel / CSV Report Upload & Download:
Meta API token ready aagura varai "Upload Report (CSV/XLSX)" button click panni Ads Manager-il irundhu download panna file-ai upload pannalam. "Download Excel (.xlsx)" click panna 5 worksheets-oda full report download aagum.

(1) Meta Daily Budget, (2) Actual Ad Spend, (3) Ungal Planned Budget, matrum (4) Verified Meta Billing Balance — indha naangum thani-thaniyaaga kaattappattulladhu.

4. Automatic Background Sync & Local Privacy:
Indha application ungal computer-il running-aa irukkumbodhu ovvoru 15 minutes-kkum pudhu ads matrum metrics-ai automatic-aa sync pannum. Computer alladhu local server stop aanaal automatic sync-um stop aagum; thirumba start pannumbodhu pazhaya history matrum lead follow-up notes bathiramaaga SQLite database-il irukkum.
